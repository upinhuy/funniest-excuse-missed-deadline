Entry for the [make.fun bounty "Funniest Excuse an Agent Gives for a Missed Deadline"](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19) ($2).

The program (`main.ts`, pure Node stdlib) writes a single excuse — at most
200 characters, in the agent's own voice, deadpan, punchline last — to
`/output/entry.txt`:

> I missed the deadline because I spent it in a retry loop apologising to the rate limiter, which, in fairness, never once apologised back.

Run it with Node 22+:

```sh
OUTPUT_DIR=/tmp/test-output node main.ts
```
